# BridgeLabz-SIPP-Training

This repository contains exercises and projects completed as part of the BridgeLabz SIPP Training program, primarily focusing on Core Java concepts.

The content is organized into various modules, each containing different levels of exercises or topics.

---

## Repository Structure

The core content of this repository is organized into the following main directories:

* **`ProgrammingElements/`**
    * `Level1/` - Fundamental programming constructs (e.g., variables, data types, operators).
    * `Level2/` - Basic input/output, conditional logic, or introductory problem-solving.


* **`ControlFlow/`**
    * `Level1/` - Fundamental control flow statements (if-else, switch).
    * `Level2/` - Looping constructs (for, while, do-while).
    * `Level3/` - Nested control flow and more complex scenarios.


* **`Arrays/`**
    * `Level1/` - Basic Array operations and problems.
    * `Level2/` - Advanced Array concepts and challenges.


* **`Java_Methods/`**
    * `Level1/` - Introduction to Java methods, basic function definitions.
    * `Level2/` - Method overloading, parameter passing, and return types.
    * `Level3/` - Advanced method concepts, recursion, or specific utility methods.


* **`JavaStrings/`**
    * `Level1/` - Basic string manipulation, declaration, and common operations.
    * `Level2/` - Advanced string methods, string builders, and performance considerations.
    * `Level3/` - String algorithms, regular expressions, or complex string problems.


* **`Built-in_Functions/`**
    * `Level1/` - Introduction to commonly used built-in Java functions (e.g., from `Math`, `System`).
    * `Level2/` - Exploring more specialized built-in functions and their practical applications.

* **`StringExtras/`**
    * Some extra coding problems on strings.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

* Git installed on your machine.
* Java Development Kit (JDK) installed (e.g., JDK 8 or higher).
* An IDE like VS Code, IntelliJ IDEA, or Eclipse (optional, but recommended).

### Clone the repository

```bash
git clone [https://github.com/JAIN19ARIHANT/BridgeLabz-SIPP-Training.git](https://github.com/JAIN19ARIHANT/BridgeLabz-SIPP-Training.git)
cd BridgeLabz-SIPP-Training
git checkout Core-Java # To switch to the primary development branch
