## JavaClassesAndObjects

This section contains programs demonstrating the concepts of classes and objects in Java.

### Level 1

* `Circle.java`: Demonstrates a simple Circle class.
* `Employee.java`: Implements an Employee class.
* `Inventory.java`: Represents an inventory system.
* `Mobile.java`: Defines a Mobile phone class.

### Level 2

* `ATM.java`: Simulates an ATM functionality.
* `MovieTicket.java`: Handles movie ticket booking.
* `PalindromeString.java`: Checks if a string is a palindrome.
* `Shoppingcart.java`: Implements a shopping cart.
* `Student.java`: Represents a Student class.

## JavaConstructors

This section focuses on the usage and types of constructors in Java.

### InstanceVsClass

This sub-section explores the difference between instance and class members, often illustrated with constructor usage.

* **Course**:
    * `Course.java`: A class related to course management.
* **ProductInventory**:
    * `ProductInventory.java`: Manages product inventory using constructors.
* **Vehicle**:
    * `Vehicle.java`: Defines a Vehicle class.

### Level 1

* `Book.java`: A class representing a Book.
* `Car.java`: Defines a Car class.
* `Circle.java`: Another example of a Circle class, possibly demonstrating different constructor types.
* `HotelBooking.java`: Handles hotel room bookings.
* `Library.java`: Implements a Library system.
* `Person.java`: A basic Person class.
